本版本变更 (4-17)
================================================================================

【核心变更】
  - 将树扩展策略从 VF-RRT (矢量场引导) 替换为标准 RRT (随机扩展)
  - 移除 computeVectorField / extendVFRRT，改用 extendRRT
  - 移除 VF 专有成员: cached_J_T_, hard_obstacle_*, consecutive_failures_
  - 移除 GraspRrtConfig::vf_activation_distance
  - 移除 GraspPlanningPerformance::vf_gradient_time_ms
  - SDF/体素梯度场保留，仅供 TrajOpt 阶段使用 (不在 RRT 中查询)

【保持不变】
  - 抓取假设策略 (connectRandomGraspPositionJacobian / moveTowardsGoal)
  - pose_sphere_ 近物体节点注册机制
  - TrajOpt 阶段 (SdfTrajOptimizer)
  - SdfCostEvaluator 构建与接口

================================================================================
规划流程
================================================================================

Phase 1: 构建 SDF/体素梯度场 (一次性, 离线)
  SdfCostEvaluator::buildSdf()

Phase 2: 标准 RRT 建树 + GraspRRT 抓取假设
  extendRRT()                  — 随机树扩展
  connectRandomGraspPositionJacobian() — 终端抓取下探 (DiffIK)

Phase 3: TrajOpt 轨迹优化
  SdfTrajOptimizer::optimize() — 使用 SDF 梯度平滑路径、降低软碰撞代价

================================================================================
快速开始
================================================================================

1. 编译项目
   $ cd grasp_rrt_framework_vf
   $ rm -rf build && mkdir build && cd build
   $ cmake ..
   $ make -j$(nproc)

2. 运行程序
   $ ./example_grasp_rrt [path_to_panda.urdf]
